➕ إضافة مصدر بيانات ODBC جديد (User DSN)

يتم تسجيل الـ DSN مباشرة في سجل الويندوز (Windows Registry) ليرتبط مع PHP بسهولة:

🔍 كود فحص الاتصال الجاهز بـ PHP

استخدم هذا الكود للاتصال بأي مصدر DSN قمت بإنشائه:

<?php
// اتصال مباشر عبر PDO ODBC
$dsn = "odbc:ERP_DB";
$pdo = new PDO($dsn, "", "");
$rows = $pdo->query("SELECT * FROM users")->fetchAll();
print_r($rows);
?>
